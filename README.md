# Nombre del proyecto: Clasificador de correos

## Objetivo

Desarrollar un modelo que permita clasificar automáticamente correos electrónicos
como spam o no spam, con el fin de mejorar la organización del correo y reducir
mensajes no deseados.

## Descripción del problema

Muchas personas reciben una gran cantidad de correos electrónicos no deseados,
conocidos como spam. Estos mensajes pueden contener publicidad, fraudes o
incluso malware. Esto provoca pérdida de tiempo y posibles riesgos de seguridad
para los usuarios.

Un sistema basado en redes neuronales puede analizar el contenido de los
correos y aprender a identificar patrones que permitan clasificarlos automáticamente.

## Impacto del proyecto:

Tecnológico: mejora los sistemas automáticos de filtrado de correo.

## Introducción

El correo electrónico es una de las herramientas de comunicación más utilizadas.
Sin embargo, junto con su crecimiento también ha aumentado la cantidad de
correos no deseados o spam. Estos mensajes pueden ser molestos e incluso
peligrosos cuando contienen enlaces fraudulentos o software malicioso.

En la actualidad, la inteligencia artificial y el aprendizaje automático
permiten desarrollar sistemas capaces de analizar grandes cantidades de datos
y reconocer patrones. Entre estas tecnologías se encuentran las redes neuronales,
que pueden aprender a identificar características específicas en los correos
electrónicos para clasificarlos correctamente.

Este proyecto propone el desarrollo de un sistema basado en una red neuronal
capaz de analizar el contenido de los correos electrónicos y determinar si
se trata de spam o de un mensaje legítimo.

## Resultados esperados y alcances

Esperamos un modelo de red neuronal que sea capaz de analizar correos electrónicos
y clasificarlos como spam o no spam con un nivel aceptable de precisión.

El sistema permitirá demostrar cómo las redes neuronales pueden utilizarse
en aplicaciones reales para mejorar la seguridad y la organización del correo
electrónico. Sin embargo, el proyecto se limitará a un conjunto de datos
específico utilizado para el entrenamiento y prueba del modelo.
